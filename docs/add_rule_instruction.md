# Инструкция по добавлению новых правил в typograf

## Общие требования
- Каждое правило должно состоять из трёх файлов:
  1. **Описание**: `названиеПравила.json` — краткое описание правила на русском и английском языках.
  2. **Логика**: `названиеПравила.ts` — файл с реализацией правила (регулярка и функция-обработчик).
  3. **Тест**: `названиеПравила.test.ts` — файл с тестами для проверки работы правила.
- Все файлы должны лежать в соответствующей папке по структуре: `src/rules/{группа}/{подгруппа}/`.
- Названия файлов и экспортируемых сущностей должны быть согласованы с остальными правилами.

## Шаги для добавления нового правила

### 1. Создать описание правила
Создайте файл `названиеПравила.json`:
```json
{
  "en-US": "описание на английском",
  "ru": "описание на русском"
}
```

### 2. Реализовать правило
Создайте файл `названиеПравила.ts` по шаблону:
```ts
import type { TypografRule } from '../../../main';

export const названиеПравилаRule: TypografRule = {
    name: 'группа/подгруппа/названиеПравила',
    handler(text) {
        // Ваша логика
        return text.replace(ВАША_РЕГУЛЯРКА, '...');
    },
};
```
- Используйте существующие константы и утилиты, если это возможно.
- Регулярные выражения должны быть максимально оптимизированы и покрывать все кейсы.

### 3. Написать тесты
Создайте файл `названиеПравила.test.ts`:
```ts
import { typografRuleTest } from '../../../../test/helpers';

typografRuleTest(['группа/подгруппа/названиеПравила', [
    [
        'исходный текст',
        'ожидаемый результат',
    ]
]]);
```
- Покройте тестами все основные и граничные случаи.
- Тесты должны быть читаемыми и однозначными.

### 4. Интеграция
- Проверьте, что новое правило добавлено в нужные индексы (`index.ts`) и доступно для использования.
- Запустите тесты: `npm test`.
- Убедитесь, что все тесты проходят успешно.

## Пример структуры
```
src/rules/common/space/

  - afterColon.ts
  - afterColon.test.ts
```

## Важно
- Не забывайте про зависимости между правилами и группами.
- Соблюдайте стиль кода и соглашения проекта.
- На каждое правило — отдельный тестовый файл.
